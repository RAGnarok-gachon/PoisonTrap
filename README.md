# PoisonTrap

RAG 챗봇 지식베이스 포이즈닝 공격 & 이상탐지 방어

## 담당

나연 혼자 진행. 공격 측(RAG 챗봇 구축, 포이즈닝 공격 시나리오)과 방어 측(자동화 스캐너, 이상탐지 필터 개발)을 모두 담당.

## 연구 질문

RAG 지식베이스에 악성 문서를 주입하는 포이즈닝 공격을 기존 자동화 레드팀 툴(DeepTeam, Garak 등)이 탐지하지 못한다면, 임베딩 유사도 기반 이상탐지로 이를 보완할 수 있는가?

## 배경

- 금융보안원 2025년 AI 레드팀 보고서: 국내 AI 공격을 4세대로 분류. 최신 공격(3~4세대)은 긴 문맥 기반 인지적 조작과 RAG 지식DB 오염 방식이며, 금융권 AI는 3세대 이상 공격에서 방어가 무력화되는 경향을 보임.
- 자동화 레드팀 툴은 커버리지는 넓지만 confidence는 낮음 — 2025년 12월 Stanford 벤치마크에서 최고 성능 자율 에이전트도 사람 테스터 80%가 찾은 취약점을 놓침.

## 저장소 구조

```
.
├── docs/           # 프로젝트 계획, 주차별 진행 기록, 발표 자료
├── rag-chatbot/    # RAG 챗봇 MVP (임베딩, 벡터DB, 검색/응답 파이프라인)
├── attacks/        # 포이즈닝 공격 시나리오 및 재현 스크립트
└── detection/      # 임베딩 기반 이상탐지 필터
```
