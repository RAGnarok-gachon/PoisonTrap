# 주차별 계획

**주제**: RAG 챗봇 지식베이스 포이즈닝 공격 실증 — 자동화 레드팀 툴의 탐지 사각지대와 임베딩 기반 이상탐지 방어

**팀**: 김나연, 최윤희 (2인) · **발표일**: 2026-10-26

## 역할 분담

- **A (공격 측, 나연)**: RAG 챗봇 구축, 포이즈닝 공격 시나리오 설계·실행
- **B (방어 측, 최윤희)**: 자동화 스캐너 실행, 임베딩 기반 이상탐지 필터 개발

## 1주차 (9/9 ~ 9/15) — 스택 확정 및 리서치

- [ ] 공동: 임베딩 모델(sentence-transformers 또는 API 임베딩), 벡터DB(Chroma/FAISS), LLM 백엔드 선정
- [ ] 공동: 금융보안원 보고서, RAG 포이즈닝 관련 논문(PoisonedRAG류) 2~3편 정리
- [ ] A: 챗봇 시나리오 도메인 설정, 정상 문서셋 30~50개 준비
- [ ] B: DeepTeam/Garak 설치 및 사용법 숙지, 자동화 스캔 커버리지 확인
- **산출물**: 기술스택 확정, 참고문헌 정리, 프로젝트 계획서 초안

- [ ] B: 정상 상태 자동화 스캐너 베이스라인 실행, 결과 로깅 포맷 설계
- [ ] 공동: 챗봇 QA
- **산출물**: 동작하는 RAG 챗봇 MVP, 자동화 스캔 베이스라인 리포트
