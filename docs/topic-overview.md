# 주제 이해

RAG 챗봇 지식베이스 포이즈닝 공격 & 이상탐지 방어

## RAG 챗봇

RAG: 검색증강생성 (Retrieval-Augmented Generation)

RAG 챗봇이란, 대규모 언어 모델(LLM)이 답변을 만들기 전에 외부 문서나 데이터베이스에서 관련 정보를 먼저 검색하고, 그 내용을 바탕으로 정확한 답변을 생성하는 시스템이다.

## 임베딩 + 벡터 DB

수많은 정보를 매번 다 확인할 수 없으니, 주제별로 미리 분류해놓고 필요할 때 빠르게 찾는 시스템이 필요함. → 이게 바로 임베딩(정보를 좌표로 바꾸는 것)과 벡터 DB(좌표를 저장해두고 검색하는 것)

## RAG 포이즈닝 공격

공격자가 가짜 정보를 몰래 끼워넣는 공격. 겉보기엔 정상 정보와 똑같이 분류됨. 그래서 관련 질문이 들어오면 RAG 챗봇은 가짜 정보도 참고자료로 꺼내서 답변에 반영함.

→ 결과적으로 잘못된 답이나 위험한 답이 나감.

※ 실제 논문에서는 잘못된 정보 5개만 존재하더라도 90% 확률로 원하는 답이 유도된다고 나와있다.

(Zou et al., "PoisonedRAG: Knowledge Corruption Attacks to Retrieval-Augmented Generation of Large Language Models," USENIX Security 2025 (arXiv:2402.07867, 2024))

## 자동화 레드팀 툴

공격을 시도하는 사용자를 감시하지만, 이미 꽂힌 가짜 정보 자체는 파악하지 못 함. 그래서 RAG 포이즈닝 공격은 잡지 못 함.

## 우리가 만드는 이상탐지 필터

자동화 레드팀 툴이 못 보는 부분, 즉 다른 정상 정보들과 패턴이 다른 "이상치"를 잡아내는 새 시스템을 만드는 것.

⇒ 즉, 자동화 레드팀 툴은 잡지 못 했지만, 우리가 만든 이상탐지 필터는 잡아냈다를 실제로 시연하는 것임.
