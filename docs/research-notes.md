## RAG 포이즈닝 논문 요약

Zou et al., "PoisonedRAG: Knowledge Corruption Attacks to Retrieval-Augmented Generation of Large Language Models," USENIX Security 2025 (arXiv:2402.07867, 2024)

**[문제의 근본]**

RAG 시스템이 답변의 근거로 삼는 외부 지식 데이터베이스가 새로운 공격 경로로 악용될 수 있음. 공격자가 소수의 악의적인 텍스트를 지식 데이터베이스에 주입하면, RAG 시스템이 이를 검색하여 사용자의 질문에 대해 공격자가 의도한 조작된 답변을 생성하게 됨.

**[해결 및 방어 방향]**

논문에서는 이 공격을 막기 위해 질문 재구성(Paraphrasing), 텍스트 난해도(Perplexity) 기반 탐지, 중복 텍스트 필터링, 지식 확장 등의 방어 기법을 실험했음. 하지만 기존의 방어법들은 PoisonedRAG를 효과적으로 막아내지 못하는 것으로 확인되었음. 따라서 외부 데이터베이스의 무결성을 철저히 검증하고, 악의적 텍스트가 검색 및 생성 조건에 부합하지 못하도록 원천 차단하는 새롭고 강력한 보안 메커니즘의 개발이 시급함.
